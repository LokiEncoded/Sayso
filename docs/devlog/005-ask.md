# 005: Ask, the first half of the speaking loop

**Date:** 2026-10-22 · **Stage:** 2 (MVP: Read + Ask)

## What we built

Select text (or nothing), hold **Ctrl+Alt+A**, ask a question out loud, let go. Tellsy records your voice, copies the selection, sends both to Google Gemini, and speaks the answer in your chosen voice.

```
hold Ctrl+Alt+A ─► pip ─► microphone records ─► let go ─► pip ─► copy selection
     ─► Gemini (audio + text, one request) ─► clean up markdown ─► Piper speaks
```

## Decisions and why

| Decision | Why | Alternative we skipped |
| --- | --- | --- |
| Gemini hears the audio directly | One request instead of two: no separate speech-to-text step, less delay, less code | Whisper (speech-to-text) and then a text-only model |
| Model `gemini-flash-latest` by default | Google renames Flash models every few months; two were deprecated this October. The alias always points at the current one | Pinning a version like `gemini-3.8-flash` (still possible in settings) |
| Hold to talk | Feels like a walkie-talkie and matches Wispr Flow; the question ends exactly when you let go | Press to start, press to stop |
| Copy the selection after you let go | While you hold Ctrl+Alt+A, our Ctrl+C would arrive as Ctrl+Alt+C | Copying first (needs you to release keys before speaking) |
| Gemini runs on a background thread, with a "generation" counter | Stop must work while Gemini thinks; a late answer to a cancelled question is dropped | Waiting on the command thread (that was devlog 002's Stop bug) |
| Errors are written to be spoken | "Gemini says you've hit your usage limit" is something you can act on; a stack trace isn't | Logging only |
| Pip tones generated in code | You know Ask heard you without looking; no sound files to ship | Speaking "Listening…" (slow, and it would be recorded) |
| 16 kHz mono WAV | The standard for speech; a minute is about 2 MB, under Gemini's 20 MB inline limit | Higher quality: bigger, no better for speech |

## Concepts to study from this step

- **REST APIs with Java's `HttpClient`:** building a POST request, headers, timeouts, and handling status codes (`GeminiAssistant.answer`).
- **JSON with Gson:** building a request tree (`JsonObject`, `JsonArray`) and walking a response.
- **Recording audio:** a `TargetDataLine` is a pipe *from* the microphone, the mirror of the `SourceDataLine` we play through.
- **Testing network code without the network:** `GeminiAssistantTest` starts a tiny HTTP server inside the test (`com.sun.net.httpserver`), points the client at it, and checks the real request.
- **Cancellation with a counter:** `AskController.generation`. Each question takes a ticket; Stop bumps the counter; an answer only plays if its ticket is still current.
- **Prompting for voice:** the system instruction asks for short, plain sentences with no markdown, and `SpeakableText` cleans up anyway, because models don't always listen.

## Exercises for you

1. Get a key, then try five questions: one about a paragraph, one about a whole email, one translation, one with nothing selected, and one silly one.
2. Change the system instruction in `GeminiAssistant.INSTRUCTIONS` to give Tellsy a personality, and hear the difference.
3. Add a setting `ask.max_sentences` and use it in the instructions instead of "two to four sentences".
